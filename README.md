# Gilbert Boadu Ampomah — Academic Website

A responsive, multi-page academic portfolio built as a dependency-free static site.

## Preview locally

Open `index.html` directly, or run a local web server from this directory:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Pages

- `index.html` — Home
- `about.html` — Academic journey and awards
- `research.html` — Research projects
- `publications.html` — Filterable publication list

## Before publishing

1. Replace the GBA portrait placeholder with a professional headshot.
2. Add research figures or graphical abstracts where permissions allow.
3. Add Google Scholar, ORCID, and GitHub links if desired.
4. Confirm whether the USC email should remain after graduation.
5. Add DOI links to publications.

The website can be deployed without a build step on GitHub Pages, Netlify, or Vercel.
